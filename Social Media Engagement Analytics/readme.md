📊 Social Media Engagement Analytics Using Python

📌 Project Overview

This project analyzes social media engagement data to identify patterns in audience interactions, post performance, and engagement rates. Python is used to clean, explore, analyze, and visualize the dataset to generate meaningful insights.

🎯 Objectives

Analyze social media engagement metrics.

Compare engagement across post types and categories.

Identify content patterns associated with higher engagement.

Explore the relationship between likes and engagement rates.

Create visualizations to communicate analytical findings.

🛠️ Tools & Technologies

Python – Data analysis and programming

Jupyter Notebook – Interactive analysis

Pandas – Data manipulation and cleaning

NumPy – Numerical operations

Matplotlib & Seaborn – Data visualization

Plotly – Interactive visualizations

📂 Dataset

The project uses social_media_engagement_5000.csv, containing 5,000 records and 19 columns related to social media posts and engagement.

The dataset is used to explore metrics such as likes, engagement rates, post categories, and post types.

🔍 Project Workflow

Data Loading – Import the dataset into Jupyter Notebook.

Data Cleaning – Check missing values, duplicates, and data types.

Exploratory Data Analysis (EDA) – Examine summary statistics and data distributions.

Data Visualization – Create charts to understand engagement patterns.

Interactive Visualization – Use Plotly to explore engagement metrics.

Insights & Conclusion – Summarize the findings and identify patterns in the data.

📈 Key Analysis

Engagement comparison across different post types.

Average engagement by post category.

Distribution of likes and engagement rates.

Relationships between numerical variables using a pair plot.

Comparison of verified and unverified accounts.

Interactive charts for exploring engagement performance.

💡 Key Findings

The analysis explores differences in engagement across content types, categories, and account verification status. Initial observations suggest that video posts perform well in average engagement, while food-related content shows strong engagement among the analyzed categories.

These findings are specific to the dataset and should not be generalized to all social media platforms.
