📌 Project Overview

This project focuses on data cleaning and visualization using Python. Using the built-in Seaborn Taxis dataset, I explored taxi trip information through different charts to identify patterns, distributions, and relationships in the data.

🎯 Project Objectives

Identify and handle missing values.

Prepare data for visualization.

Explore taxi fares, trip distances, tips, and payment methods.

Analyze relationships between numerical variables.

Compare taxi trips across pickup boroughs and zones.

🧹 Data Cleaning

The dataset preparation process includes:

Checking missing values in each column.

Filling numerical missing values using the median.

Filling categorical missing values using the mode.

Converting pickup timestamps into datetime format.

Removing rows without valid pickup timestamps.

Preparing the required columns for visualization.

💡 Key Learnings

Through this project, I practiced:

Data preprocessing and missing-value handling.

Exploratory Data Analysis (EDA).

Creating and customizing charts using Python.

Understanding correlations and data distributions.

Presenting data insights through visualizations.
