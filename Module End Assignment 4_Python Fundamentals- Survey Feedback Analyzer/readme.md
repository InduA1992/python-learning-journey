# Survey Feedback Analyzer

## 📌 Overview

Survey Feedback Analyzer is a Python project that analyzes customer survey feedback.

The Assignment uses basic Python concepts such as:

- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- String operations
- User input

## 🎯 Objectives

The assignment performs the following tasks:

1. Stores preloaded survey feedback.
2. Allows users to add new feedback.
3. Cleans the feedback text.
4. Counts feedback containing specific words.
5. Calculates the average rating.
6. Finds the longest feedback.
7. Finds unique words.
8. Sorts feedback based on rating.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook

## 📊 Features

### Add Feedback

Users can enter:

- Name
- Feedback
- Rating

The serial number is automatically generated.

### Text Cleaning

The program:

- Removes punctuation
- Removes extra spaces
- Converts text to lowercase

### Word Count Analysis

The program can count how many feedbacks contain words such as:

- Good
- Poor
- Excellent

Users can also enter a word of their choice.

### Average Rating

The program calculates the average rating of all feedbacks.

### Longest Feedback

The program finds the feedback containing the highest number of words.

### Unique Words

The program identifies all unique words used in the feedback.

### Rating Sort

Feedbacks can be sorted from the highest rating to the lowest rating using `zip()` and `sorted()`.
