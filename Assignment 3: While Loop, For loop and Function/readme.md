📂 Programs
1. Number Guessing Game

A simple game where the computer generates a random number between 1 and 10. The user gets up to 3 valid guesses to find the number.

Concepts: while, if-elif-else, break, continue, loop else, random.randint().

2. Multiplication Table Generator

Takes a number from the user and generates its multiplication table from 1 to 10.

Concepts: for loop, range(), user input and arithmetic operations.

3. BMI Calculator

Calculates BMI using the user's weight and height through a user-defined function.

Formula:

BMI = Weight (kg) / Height (m)²

Concepts: Functions, parameters, return, user input and mathematical calculations.
