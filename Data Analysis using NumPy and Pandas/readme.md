Python DA Assignment 1: Data Analysis using NumPy and Pandas

📌 Overview

This project focuses on learning the basics of Python data analysis using NumPy and Pandas. It covers array operations, data selection, filtering, calculations, and data manipulation through practical examples.

🎯 Objectives
•	Understand NumPy arrays and their properties.
•	Perform numerical calculations using temperature data.
•	Learn indexing and slicing in NumPy.
•	Create and manipulate Pandas Series.
•	Explore and analyze transaction data using Pandas DataFrames.
•	Practice filtering, grouping, and modifying data.

🛠️ Tools and Technologies
•	Python
•	NumPy
•	Pandas
•	Jupyter Notebook

📊 Tasks

1. NumPy Array Operations
•	Created a one-dimensional array containing Week 1 temperatures.
•	Checked the array shape, data type, and number of elements.
•	Converted Celsius temperatures to Fahrenheit.
•	Calculated maximum, minimum, and average temperatures.
•	Practiced array indexing and slicing.
•	Created a two-dimensional array to compare temperatures across two weeks.
•	Extracted weekly and weekend temperatures.

2. Pandas Series
•	Created a Series containing student marks with custom rank labels.
•	Accessed values using indexing, loc, and iloc.
•	Filtered students with marks greater than 90.
•	Modified the first-rank student's mark.
•	Removed the last-rank entry.
•	Calculated CGPA by dividing marks by 10.

3. Pandas DataFrame
•	Created a transaction dataset containing transaction IDs, product categories, regions, and amounts.
•	Explored the dataset using head(), tail(), shape, and info().
•	Selected specific columns and filtered transactions.
•	Counted product categories and identified unique regions.
•	Calculated the average transaction amount for each region.
•	Updated a transaction amount, created a discount column, and removed specified data.

📚 Key Learnings

Through this assignment, I gained practical experience in:
•	Creating and working with NumPy arrays.
•	Performing numerical calculations.
•	Understanding indexing and slicing.
•	Using Pandas Series and DataFrames.
•	Filtering and grouping data.
•	Modifying rows and columns in a dataset.
•	Performing basic data exploration and analysis.

🚀 Conclusion
This assignment helped me build a foundation in Python data analysis using NumPy and Pandas. It improved my understanding of numerical operations, data selection, and data manipulation, which are essential skills for further learning in data analytics.
